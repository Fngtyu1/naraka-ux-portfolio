# 入局有路：永劫无间新手成长体验 UX 概念作品

原创非官方 / PC 端 / 2026-10-14 / V1.0

## 30 秒打开
先解压 ZIP，再双击 index.html。无需安装、联网、登录或服务器。推荐当前 Chrome/Edge。若浏览器限制本地保存，可继续操作并导出 JSON。PDF 链接要求与 HTML 保持同一目录。

## 3 分钟展示
1. 从成长路径开始三题练习。
2. 故意选错一次，读解释；查看一次提示。
3. 完成后查看薄弱信号，点击定向重练。
4. 保存笔记、导出本地记录；刷新验证保存；清空会有确认。
5. 打开 PDF，解释研究边界、首次无提示正确率和测试计划。

## 文件
- index.html：响应式、离线单文件原型，无外部依赖。

## 证据与数据
未开展访谈、问卷、玩家可用性测试或内部数据分析。PDF 中的人群、旅程、机会和提升目标均为假设或计划，不是研究发现。原型统计只反映本浏览器演示操作；包含重复和提示作答，不能证明学习效果。

## 原型边界
只验证信息架构、概念理解、反馈和下一步路径；不模拟真实战斗、动画、时机、帧数、武器和网络。PC 规则须结合当前游戏版本和专家复核。网页不连接游戏，不改变账号或游戏数据。
